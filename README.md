# Java PERT Project

מימוש של מודל PERT (Program Evaluation and Review Technique) ב-Java, כתרגיל בירושה ופולימורפיזם בקורס "תכנות מונחה עצמים" במכללת כנרת.

A small PERT (task-scheduling) model in Java, written as an OOP course exercise on inheritance and polymorphism.

## מה התוכנית עושה

מקבלים קבוצת משימות ותלויות קדם ביניהן (משימה i חייבת להסתיים לפני משימה j), והתוכנית מחלקת אותן לשלבי ביצוע: בכל שלב נכנסות כל המשימות שכל התלויות שלהן כבר הושלמו.

## מבנה המחלקות

| מחלקה | תפקיד |
|-------|-------|
| Pert | מחלקת הבסיס: ניהול משימות ותלויות קדם, חלוקה לשלבים והדפסתם |
| TimedPert | יורשת מ-Pert ומוסיפה משך זמן לכל משימה; מחשבת את זמן ההתחלה של כל שלב ואת משך הפרויקט הכולל |
| Courses | יורשת מ-Pert ומייצגת תוכנית לימודים: המשימות הן קורסים עם שמות, והתלויות הן דרישות קדם |
| PertInheritanceApp | תוכנית הרצה לדוגמה: בונה תוכנית לימודים של 12 קורסים בהנדסת תוכנה ומדפיסה אותה לפי שלבים |

המחלקות היורשות דורסות (override) את printTask ו-printStage, וכך אותו אלגוריתם של חלוקה לשלבים משמש לשלושה שימושים שונים.

## הרצה

פותחים את התיקייה ב-IntelliJ IDEA ומריצים את PertInheritanceApp.java.
